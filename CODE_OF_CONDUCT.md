# GitVerse Contributor Guidelines & Code of Conduct

The GitVerse project is built upon open, constructive, and disciplined technical collaboration. We welcome contributors from all backgrounds and skill levels.

## Core Principles

1. **Constructive Technical Discussions**: Focus on code quality, performance, usability, and architecture. Critique ideas, implementations, and design patterns—never individuals.
2. **Mutual Respect**: Treat every participant with courtesy, patience, and professional respect regardless of their background or level of experience.
3. **Engineering Rigor**: Respect project standards outlined in `AGENTS.md`, including clean naming conventions, bidirectional layout support, and comprehensive test coverage.
4. **Transparent Communication**: Explain architectural choices, trade-offs, and design rationale openly in PR descriptions and issue discussions.

## Project Leadership & Inquiries

Project maintainers actively review community contributions and are dedicated to maintaining a safe, productive development space. Any concerns regarding community interaction can be directed to the repository maintainers via project discussions.
